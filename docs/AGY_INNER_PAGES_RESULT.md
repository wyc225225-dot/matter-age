## 一、自主实测路径与操作步骤

构建最新产物并在本地启动 `vite preview`，通过 Playwright 真实驱动 Chromium 分别在 **手机竖屏（`390×844`）**、**手机横屏（`844×390`）** 与 **桌面（`1280×800`）** 完整体验以下内部流程并逐屏截图取证：

1. **自由探索实验台（简单模式）**：空台面初态 → 点击空槽打开选料面板 → 进入标本补给领取过氧化氢与二氧化锰 → 选水并选择「冷却」执行凝固 → 放入过氧化氢 + 二氧化锰触发失败诊断 → 查看结果反馈与记录页签。
2. **自由探索实验台（进阶定量模式）**：切换进阶模式 → 选入多份物质并调整 `− / 输入 / +` 份数 → 选条件与催化剂执行电解 → 审阅 `StoichiometryReport` → 切换「方程式配平研究」选择方程式并调整系数。
3. **关卡挑战与特殊挑战**：切换简单 / 进阶定量 / 特殊挑战页签 → 进入进阶定量挑战实验台 → 进入特殊挑战（极限实验 `极限氢氧：4 份水起手`）进行投料与条件切换。
4. **挑战历史（活跃章节）**：直达 `#history/hist_01` 背景页与 `#history/hist_04` 伏打电堆第 3 阶段装配界面。
5. **经营 / 世界 / 科技 / 图鉴 / 知识库**：逐一检查经营订单与有限库存制备、世界探索地图、科技树、我的物质图鉴与本地知识库列表。

## 二、自主发现的问题、证据与根因分析

按严重度独立分级（P0 阻断/不可用、P1 核心交互混乱、P2 细节排版瑕疵）：

| 优先级 | 影响场景 | 实测观察证据 | 根因分析 |
|---|---|---|---|
| **P0** | **手机横屏实验台选料** (`844×390`) | 右侧「材料」栏中 `.warehouse-grid` 被压缩为约 **10px 的细缝**，水/空气/木材等卡片完全不可见且自动化点击 `添加水` 失败无法激活「开始实验」。 | `.lab.lab-landscape-mode .warehouse` 使用定高 `flex-direction: column`，其内部 `warehouse-tabs` + `search-box` + 双原生 `<select>` + 底部 `supply-button` 合计占去 ~170px，把 `flex: 1` 的 `.warehouse-grid` 挤扁。 |
| **P0** | **实验台首屏严重拥挤** (竖屏 `390×844` + 桌面 `1280×800`) | 竖屏顶部叠放 6 层条栏（顶栏+二级栏+标题+模式栏+操作台切换+面板头，~266px），底部双固定栏（118px），加上空闲态 ~155px 的空结果占位框，导致「独立催化剂栏」被挤出竖屏视口；甚至桌面 `1280×800` 下全部 11 项条件和「开始实验」按钮均落在首屏以下。 | 闲置态 `.result-area` 常驻大尺寸占位图，且顶部多重标题与边距缺乏层级压缩，导致核心操作链（槽位→条件→催化剂→执行）被截断。 |
| **P1** | **实验台各类选择控件体验差** | ① 11 项条件按钮选中态与未选中态对比度过低（`#344f5e` vs `#20313f`），且无已选计数与快速清空；② 独立催化剂栏依赖极小原生 `<select>`，未解锁催化剂时显示空下拉框令玩家困惑；③ 选料面板用双原生 `<select>` 筛类别与排序，触发系统滚轮；④ 标本补给含 63 项却无搜索框；⑤ 进阶模式槽位高达 ~215px 且数字输入框因浏览器默认微调箭头导致数字偏左。 | 早期组件沿用桌面原生表单元素，未针对触控高频单选与即时视觉反馈进行统一设计。 |
| **P1** | **方程式配平选择器错乱** (竖屏) | 「选择研究方程式：」被挤压折成三行竖排（`选择研 / 究方程 / 式:`），且 136 道题只能靠长下拉框翻找。 | `.balancing-picker label` 为单行横向 `flex` 且未对文字设置 `white-space: nowrap` 或上下布局，也缺少上/下一题切换。 |
| **P1** | **特殊挑战页面双层头部与文字粘连** (`390×844`) | 进入特殊挑战后，顶部已有 `< 返回关卡挑战`，下方仍残留「目标挑战」大标题、星级条、三模式页签以及组件内部第二个 `< 返回挑战列表`；且原料项显示为 `水库存 4 份`（名称与库存粘连无间距）。 | `Challenges.tsx` 在 `activeSpecial` 激活时未隐藏列表页头部与筛选栏；`SpecialChallengeRunner` 未区分移动端已有顶栏返回；`.special-inv-item > div` 未设置纵向排版与间距。 |
| **P2** | **多处内页细节瑕疵** | ① 挑战列表手机端三模式页签过长导致「特殊挑战」被裁切在右侧屏幕外；② 图鉴中已定量研究的绿色天平徽章 `.quant-badge-icon` 直接压在 `NO. 001` 编号上，双下拉框居中未撑满；③ 世界地图 `采集 0任务 0/2` 零间距粘连；④ 知识库 `532 条结果` 独占一整行空白；⑤ Ch.04 伏打电堆「清空电堆」在 2 列网格孤悬第 3 行；⑥ 经营生产「仅看可生产」不显示当前就绪数量。 | 局部 CSS 定位冲突（`top/left` 与编号重合）、缺少 `gap` 与网格对称性规划。 |

## 三、正式工程（`src/`）实际实施的优化方案

严格遵守 `AGENTS.md` 约定，保留全部既有玩法、中文文案、v3 存档、深链、科学/库存隔离及零外部溯源展示，未触动任何引擎科学规则与数据库。改动集中于 UI 与交互层：

1. **实验台核心布局与全视口首屏收敛**（`src/pages/Laboratory.tsx`、`src/styles/inner-polish.css`、`src/main.tsx`）：
   - **彻底修复横屏仓库塌陷（P0）**：横屏 `.warehouse` 改为整栏自然纵向滚动，`.warehouse-grid` 解除 `flex: 1; overflow: auto` 挤压并展示完整 3 列卡片；合并收藏/排序芯片与「领标本」入口至顶部单行，并用紧凑横向类别胶囊取代双原生下拉。
   - **动态闲置状态条（P0）**：当尚无实验结果/诊断/计量报告时，`.result-area.idle-compact` 自动收敛为单行实时配置摘要（如 `已选 过氧化氢 · 混合 · 催化:二氧化锰`），执行后立即完整展开结果、动画、失败诊断或 `StoichiometryReport` 并平滑定位结果区。
   - **桌面 `1280×800` 与手机 `390×844` 首屏全露出**：压缩自由实验多余垂直留白（同时保留语义 `<h1>` 可见），桌面端催化剂栏改为横向布局，使 4 槽位 + 实时状态条 + 11 条件 + 催化剂栏 + 主执行按钮全部落在 `1280×800` 首屏内免滚动操作。
2. **实验台全部选择操作升级**（`src/pages/Laboratory.tsx`、`src/App.tsx`、`src/styles/inner-polish.css`）：
   - **条件选择**：高亮选中渐变边框与投影，顶部显示 `已选 N` 计数与一键「清空条件」。
   - **独立催化剂栏**：已解锁催化剂直接以带图标的一键触控胶囊（`不使用` + 各催化剂）呈现，未解锁时清晰提示「暂未解锁催化剂（解锁二氧化锰等后可选）」；同步保留可访问 `<select aria-label="选择催化剂">` 确保无障碍与自动化兼容。
   - **选料面板与标本补给**：移动端选料面板改为单点横向类别胶囊 + 排序切换芯片 + 搜索框一键清空；`App.tsx` 标本补给弹窗新增 `SPECIMEN COLLECTION · 已收集/63` 进度与即时搜索框。
   - **进阶份数与配平选择器**：重构 `.advanced-slot` 为紧凑头栏（图标+名称/化学式+有限库存上限）+ 去原生微调箭头的居中触控步进器；配平选择器改为清晰顶标 + `当前/总数` + 上/下一道快捷按钮。
3. **挑战、历史、经营、图鉴、知识库与世界地图内页清理**：
   - `src/pages/Challenges.tsx` & `src/components/SpecialChallengeRunner.tsx`：进入特殊挑战时自动隐藏列表大标题与模式栏，移动端隐藏重复「返回挑战列表」按钮；修复库存项图文间距并支持点击卡片直接加料，升级特殊挑战条件与催化剂为高亮胶囊，反馈条置顶展示防遮挡；挑战列表三模式页签在移动端等宽 3 列排布零截断。
   - `src/pages/History.tsx`：Ch.04 伏打电堆将「清空电堆」归入电压表卡片，使 4 个组件按钮呈对称 2×2 网格，电极组合切换改为 3 列紧凑网格。
   - `src/pages/Management.tsx`：生产页「仅看可生产」实时显示可生产配方数量，并标注当前展示/匹配总数。
   - `src/components/KnowledgeLibrary.tsx` & `src/styles/inner-polish.css`：结果总数内联至搜索框右侧；图鉴 Lv.2 天平徽章移至右上角彻底避开 `NO. 001` 编号，筛选下拉等宽铺满；世界地图 `.region-stat-line` 补充间距。
