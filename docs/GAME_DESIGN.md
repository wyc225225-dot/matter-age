# Matter Age · V1.6 游戏系统设计（GAME DESIGN）

## 1. 核心长期循环

V1.6 在保留 V1.0 自由探索、V1.5 整数化学计量/配平与本地 GitHub 化学知识库的基础上，建立了「探索—经营—科技—历史—收藏」长期游戏循环：

```
自由探索 / 世界探索（原始森林免费采集 · 矿石山脉 · 海洋盐湖）
        │
        ▼
实验室经营（有限库存生产 → 交付 30 项研究订单 → 获取金币 / RP / 累计经验）
        │
        ├──▶ 科技研究树（24 项无环 DAG 科技）──▶ 解锁新设备 / 区域 / 实验室升级资格
        ├──▶ 实验设备工坊（8 台功能设备）──▶ 解锁经营条件与批量上限 + 2D 等距实验台视觉成长
        ├──▶ 实验室升级（Lv.1 → Lv.2 → Lv.3）──▶ 扩充订单槽位、设备容量与高阶市场
        ├──▶ 挑战历史（5 章独立交互谜题）──▶ 获得首通/复玩奖励与历史馆藏
        └──▶ 科学博物馆（16 件事件驱动藏品）与 34 项科学成就
```

## 2. 六大玩法模式与难度解耦

- **玩法模式（大厅 6 入口）**：
  1. `自由探索`（`#lab`）：无限实验台、全部 10 项条件开放、支持简单模式与进阶定量/配平模式。
  2. `实验室经营`（`#management`）：有限库存生产、研究订单、设备工坊、原料市场与 2D 等距实验台升级。
  3. `目标挑战`（`#challenge`）：36 简单挑战 + 36 进阶定量挑战 + 15 特殊推理挑战（共 87 关）。
  4. `挑战历史`（`#history` 与 `#history/<chapterId>` 深链）：对齐 `HISTORY_MODE_BRIEF.md` 的 10 章科学史时间线，第 01/02/03/04/07 章完整可玩（可恢复五阶段研究会话、5 种独立实验谜题、简单/进阶双难度、多维星级评定、防刷有限奖励、解锁科学家档案/历史手稿/理论条目/勋章/纪念仪并直链博物馆与科技树）。
  5. `世界探索`（`#world`）：2D 交互式区域地图（3 可玩 + 3 预告）、野外采集、区域任务与随机奇遇。
  6. `工业文明`（锁定预告）：预留 V1.7 能源管网与 V2.0 自动化产线接口，不伪造未实现功能。
- **实验难度模型**：简单模式（V1.0）/ 进阶定量模式（V1.5）/ 困难模式（V2.0 锁定）。

## 3. 严格四套库存隔离

| 场景 | 库存机制 | 隔离规则 |
|---|---|---|
| 自由探索（`#lab`） | 解锁集合（`discovered`），单次实验投入不扣减全局解锁 | 标本补给仅作用于自由探索，不增加经营库存 |
| 简单/定量/特殊挑战 | 关卡独立临时库存（`challengeRun` / `quantitativeChallengeRun` / Runner 本地态） | 禁止自由库存渗入，挑战产物不泄漏回自由或经营库存 |
| 实验室经营与世界探索 | 有限非负整数库存（`managementInventory`） | 生产/交付/出售严格原子扣减，设备条件限制仅在经营模式生效 |
| 挑战历史 | 章节独立材料展示与独立谜题态 | 仅消耗章节内部交互步骤，不扣减经营或自由库存 |

## 4. 视觉与导航架构

- **主题气质**：深蓝精密仪器实验室基调；挑战历史采用古铜金与档案羊皮纸点缀；科学博物馆采用暗展厅聚光灯展柜；实验室经营配备 Lv.1→Lv.3 视觉成长的 2D 等距 SVG 实验台；世界探索采用 2D 手绘风格地形与可点击节点地图。
- **桌面端**：单行顶栏主导航 + 实时金币/RP 芯片 + 博物馆/成就/设置快捷入口（1440px 单行不折行，768px 自动换行居中无裁切）。
- **移动端（<=760px）**：底部 5 项清晰主导航（`大厅` / `探索` / `经营` / `挑战` / `更多`）+ 上滑抽屉直达全部二级档案页面，全程零横向滚动。
