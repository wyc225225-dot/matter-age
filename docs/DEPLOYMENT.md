# GitHub 与朋友试玩

- 仓库： https://github.com/wyc225225-dot/matter-age
- 试玩： https://wyc225225-dot.github.io/matter-age/

向 main 推送后，GitHub Actions 自动安装依赖、单元测试、校验数据、构建并部署 Pages。部署构建设置 GITHUB_PAGES=true，使 Vite 和 PWA 使用 /matter-age/ 路径；本地 npm run dev 继续使用根路径。

玩家无需安装或注册。进度存在各自浏览器中，不会上传到 GitHub。清除网站数据或切换浏览器不会自动同步进度，可通过设置里的 JSON 导入/导出备份。

当前分享的是带开发预览标记的可玩版本。来源资料保留在源码，不在玩家页面显示。本机日志、会话授权配置、代码备份、node_modules、测试产物与上游仓库副本不上传。
