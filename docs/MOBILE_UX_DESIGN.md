# Matter Age 手机端全模式交互重设计方案（MOBILE_UX_DESIGN）

更新时间：2026-11-25  
适用范围：V1.6 全部 13 个路由视图与 5 个可玩挑战历史章节（UI-only 交互与响应式架构重构；不改化学引擎、科学数据、经济结算与存档语义，完整保留桌面与 768px 平板体验）

---

## 1. 响应式视口分层与横屏防误判策略

现有实现仅依赖 `@media (max-width: 760px)`，导致手机横屏（如 `844×390`、`800×360`、`812×375`）因宽度超过 `760px` 被误判为平板/桌面布局：顶部导航折行占据 130px+ 高度，多栏被挤爆或竖向堆叠出屏幕。

### 1.1 四类视口契约（宽度 × 高度 × 方向组合）

通过统一 `src/hooks/useViewport.ts` 与 `src/styles/mobile-ux.css` 维护四类清晰边界（不强制锁定屏幕方向、不提示用户必须旋转）：

| 模式 | CSS 判定条件 | 典型设备 | 导航形态 | 核心布局模型 |
| --- | --- | --- | --- | --- |
| **手机竖屏 (`mobile-portrait`)** | `(max-width: 760px) and (min-height: 521px)`，或 `(max-width: 559px)` | `360×800`、`390×844` | 底部 5 项固定导航栏 (`56px + safe-area-bottom`) + 底部抽屉 | 单屏聚焦：精简顶栏 + 吸顶子页签/任务条 + 局部滚动/抽屉选料 + 必要时单条底部操作栏 |
| **手机横屏 (`mobile-landscape`)** | `(max-height: 520px) and (min-width: 560px) and (max-width: 960px)` | `800×360`、`844×390` | **左侧垂直紧凑导航轨 (`58px + safe-area-left`)**，彻底释放底部高度 | **宽屏游戏双栏布局**：左栏核心画面/实验台/地图/装置，右栏可切换操作面板与固定主动作栏，双栏各自内部滚动 |
| **平板 (`tablet`)** | `(min-width: 761px) and (max-width: 1180px) and (min-height: 521px)` | `768×1024`、`768×844` | 保留桌面顶部导航 | 2 列平衡网格，保留完整可视化区域与详情 |
| **桌面 (`desktop`)** | `(min-width: 1181px) and (min-height: 521px)` | `1280×900`、`1440×900` | 完整顶栏 | 保持原有三栏实验台与宽屏布局零回归 |

### 1.2 全局固定层、安全区与 Z-Index 协调规范

使用 CSS 变量统一管理各层高度与间距，避免多个 `fixed/sticky` 条互相遮挡或挤压中间内容区：

- `--mobile-topbar-h: 48px`（竖屏）/ `36px`（横屏）
- `--mobile-nav-h: 58px`（竖屏底部导航）/ `0px`（横屏移至左侧 `58px` 导航轨 `--mobile-rail-w: 58px`）
- `--mobile-dock-h: 58px`（仅在需要常驻提交/实验动作的页面启用，且每页至多一条合并后的动作条）
- **Z-Index 层级**：页面吸顶条 (`z-index: 25`) < 底部操作栏 (`45`) < 移动主导航/侧轨 (`50`) < 底部抽屉与反应详情面板 (`65`) < 选料弹窗/物质详情/标本补给弹窗 (`80`) < Toast 提示 (`95`)
- **安全区与软键盘**：
  - 所有底部固定层自动叠加 `env(safe-area-inset-bottom)`；横屏左轨叠加 `env(safe-area-inset-left)`，主容器右侧预留 `env(safe-area-inset-right)`。
  - 所有移动端输入框使用 `font-size: 16px`（防止 iOS Safari 聚焦自动放大导致页面错位）；内部滚动区启用 `overscroll-behavior: contain` 与 `-webkit-overflow-scrolling: touch`。
  - 底部 `footer` 在移动端大幅精简并与固定导航/操作条留足底部留白；Toast 浮层在移动端允许自动换行（`white-space: normal`），并针对实验台、挑战历史、特殊挑战运行器分别预留底部动作条避让高度。

### 1.3 一级与二级入口信息架构与路由映射

为避免入口重复、多条全局导航竞争或每页铺满长列表，移动端收敛为 **5 个稳定的一级玩家目的入口** + **按域呈现的二级模式导航条（`.domain-subnav`）** + **分类「更多」抽屉**：

| 一级入口（底部 5 项 / 横屏左轨） | 玩家目的 | 二级入口（`.domain-subnav` / 子页签） | 对应路由与深链 | 桌面端保留策略 |
| --- | --- | --- | --- | --- |
| **大厅** | 总览、续玩与任务 | 大厅内分段页签：`玩法大厅` / `任务与难度` / `图鉴与收藏` | `#home` | 完整保留桌面大厅与顶部主导航 |
| **实验** | 所有化学实验与关卡 | 二级导航条：`自由实验`（内含简单/进阶/配平切换） / `目标挑战`（简单36/定量36/特殊15） / `挑战历史`（10章时间线 + 5章可玩 + 档案） | `#lab`、`#challenge`、`#history`、`#history/<id>` | 桌面保留直达顶栏；移动端统一归入「实验」域 |
| **经营** | 资源采集、科技与生产 | 二级导航条：`实验室经营` / `科技研究` / `世界探索` | `#management`、`#tech`、`#world` | 桌面保留直达顶栏；移动端最多 2 步直达任一生产/采集/研究页 |
| **图鉴** | 知识检索、网络与收藏 | 二级导航条：`物质图鉴`（内含 5 个档案库标签） / `发现网络` / `科学博物馆` | `#book`、`#tree`、`#museum` | 桌面保留顶栏与快捷图标 |
| **更多** | 进度总览与系统设置 | 分类抽屉（进度与系统 + 全玩法快捷直达）：`科技演进` / `探索成就` / `实验室设置` | `#eras`、`#achievements`、`#settings` | 桌面顶栏直接保留成就/设置入口 |

- **横屏空间零浪费**：在手机横屏（`mobile-landscape`）下，二级导航条 `.domain-subnav` 直接内联嵌入 `36px` 顶栏中间区域，不再额外占用垂直高度。
- **状态与路径清晰**：一级入口高亮当前所属域，二级导航高亮当前模式，保留全部既有 `#hash` 深链（如 `#history/hist_04`）、刷新恢复与模式持久化状态。

## 2. 全模式逐页现存问题与重设计方案

### 2.1 探索大厅（`Home.tsx`）
- **现存问题**：竖屏把状态栏、高大 Hero、6 张全宽模式卡片、4 张任务卡、3 张难度卡、3 张档案卡与 9 张物质收藏纵向堆叠，总长超 4000px，首屏看不到全部核心玩法入口。
- **竖屏改造**：
  - 顶部精简为紧凑单行研究者状态条（等级 + XP 条 + 可横向轻滑的资源胶囊）。
  - 紧缩 Hero 为游戏大厅快捷横幅（标题 + 统计三数 + `进入实验室` / `实验室经营` 双主按钮）。
  - 引入移动端 **大厅分段页签**（`玩法大厅` | `任务与难度` | `图鉴与收藏`），吸顶在顶部。默认「玩法大厅」首屏即以 **2 列紧凑游戏入口网格** 呈现全部 6 大模式（含工业文明锁定预告）；切至「任务与难度」一屏查看实时任务板与简单/进阶/困难难度卡片；切至「图鉴与收藏」查看科技/发现树/博物馆快捷入口与最近发现。
- **横屏改造**：双栏一屏布局——左栏（42%）展示研究者状态 + 紧凑 Hero + 主 CTA；右栏（58%）展示吸顶分段页签 + 内部滚动网格（6 模式 2×3 / 实时任务 / 难度与收藏）。

### 2.2 自由探索与进阶定量实验台（`Laboratory.tsx` + `mobile-laboratory.css`）
- **现存问题**：
  1. 竖屏虽有独立选料弹窗与底部操作栏，但模式栏、挑战横幅、台面、11 项条件、内联操作按钮与底部整套 `lab-sidebar`（实验记录 + 科学原理）仍堆成长页面；底部常驻栏与内联「开始实验」按钮功能重复且缺少快速「提示」入口。
  2. 手机横屏因宽度 `>760px` 误入桌面三栏，被挤爆或竖向拉长。
  3. 进阶模式定量报告（指标 + 双表 + 原子重排）展开后把条件区推到很下方。
- **竖屏改造**：
  - 保留全部现有选料弹窗能力与无障碍标识（`物质槽位 1` 打开选料、`选择实验物质` 对话框、顶部固定已选 4 槽、独立滚动 3 列物料网格、完成返回台面、Escape/焦点恢复），并微调间距确保 360px 零溢出。
  - 在手机竖屏为实验台增加 **分段子视图**（`实验台面` | `记录与原理` 含新结果提示点），把原本沉在页面最底部的实验手记与科学解释变成一键切换，缩短实验页纵向长度 50%+。
  - 挑战模式下将目标与剩余次数压缩为紧凑吸顶任务条；隐藏与底部常驻条重复的内联主按钮，将底部 `.mobile-experiment-dock` 升级为统一操作条：`[选物质 n/4]` + `[提示]` + `[开始实验 / 执行定量实验]`（并展示已选条件计数）。
  - 方程式配平研究模式（`EquationStudio`）紧凑化系数步进器并吸顶「检验配平」动作。
- **横屏改造**：
  - 采用 **宽屏实验台双栏布局**：左栏（54%，内部滚动）固定呈现模式/挑战条 + 2×2 实验槽位 + 实时反应结果/定量报告；右栏（46%，独立内部滚动 + 固定底部操作栏）提供 3 个页签（`材料库` | `条件与催化` | `记录与原理`），点击左栏空槽自动切到右栏「材料库」，底部常驻已选计数、`清空`、`提示` 与 `开始实验/执行定量实验`！无需弹窗打断即可边选料边看台面。
- **实验失败时的纯引擎催化剂角色诊断与上下文提示（无侵入式自动引导）**：
  - **触发原则**：遵循用户优先级指令「就实验失败的时候给提示」——**不设**首次进入自动弹窗/自动教程，**不写入**教程进度存档，**不**在实验失败前主动打断或静默改选。
  - **纯引擎诊断（`src/engine/reactionEngine.ts` · `diagnoseExperimentFailure`）**：仅在实验失败时，由纯引擎基于共享 `reactions.json` 实时诊断，React/UI 不写死任何物质 ID 或推断反应：
    - 当玩家将某条规则中的催化剂误放入反应物槽（如 `过氧化氢 + 二氧化锰` 同时选入反应物槽），引擎识别出 `二氧化锰` 在 `过氧化氢催化分解 (r027)` 中担任催化剂角色，且明确告知缺失条件（如「混合」），不将其当作消耗反应物，也不静默吞掉非催化剂多余材料。
    - UI 展示全宽诊断卡片，提供玩家确认的 **一键移至催化剂栏** 按钮（移除反应物槽对应物质并设置独立催化剂栏）与 **撤回角色调整** 按钮；多候选歧义时列出全部候选供玩家自选；同时高亮提示缺失的反应条件按钮，绝不自动替玩家运行或放宽匹配伪造成功。
    - 保留「单选过氧化氢 → 手动选催化剂」原流程，简单模式、进阶定量模式与有限库存挑战严格维持催化剂独立角色、数量/催化剂次数与库存隔离语义。

### 2.3 目标挑战与特殊挑战（`Challenges.tsx` + `SpecialChallengeRunner.tsx`）
- **现存问题**：
  - 挑战列表一次渲染 36 关（3 组）或 15 关（5 组），在手机上需连续滑动十几屏。
  - 特殊挑战运行器（`SpecialChallengeRunner`）将目标、库存加减器、条件按钮与提交按钮竖排，调节份数时目标与提交按钮滚出屏幕。
- **竖屏改造**：
  - 列表页：顶部吸顶 **模式分段条**（`简单 36` | `定量 36` | `特殊 15`）+ **分组筛选胶囊**（移动端默认聚焦首组并支持一键切至 `全部` 或任一分组，每屏只浏览 3–12 关，彻底告别 36 关长滚动）。
  - 特殊挑战运行器：顶部吸顶 **目标与步数摘要条**（目标物质/零浪费提示 + 步数 `n/上限` + 返回/重置），中间区内部操作（库存步进/试剂台/候选池 + 条件），底部固定 **已选摘要 + 反馈 + 主提交动作条**。
- **横屏改造**：列表页左侧紧凑模式/分组筛选、右侧 2 列可滚动关卡网格；特殊挑战运行器左栏为目标与原料/试剂台，右栏为条件/候选与固定提交反馈区。

### 2.4 世界探索（`WorldMap.tsx`）
- **现存问题**：2D SVG 地图、6 个区域标签与完整区域详情（介绍 + 采集点 + 任务 + 奇遇日志）竖向堆叠；在地图点选区域后看不到下方采集按钮，下滑采集后又看不到地图。
- **竖屏改造**：
  - 顶部吸顶紧凑资源 + 横向可滑动区域切换条（直接显示解锁/锁定状态）。
  - 2D 交互地图支持紧凑高度展示与一键 `收起地图 / 展开地图` 切换，点选地图区域即时刷新下方当前面板。
  - 下方区域详情拆分为 **3 个分段页签**（`野外采集点` | `区域任务` 带可领红点 | `奇遇记录`），首屏即可同时看到地图与当前区域采集按钮！
- **横屏改造**：真正宽屏地图双栏——左栏（54%）固定呈现 2D SVG 地图与底部紧凑区域胶囊；右栏（46%）吸顶区域名称与分段页签（`采集` / `任务` / `奇遇`），卡片列表在右栏内部独立滚动。

### 2.5 实验室经营（`Management.tsx`）
- **现存问题**：顶部 `IsometricLabBench`（~280px）与 `lab-upgrade-panel`（~380px）占满整个首屏，玩家每次进入经营都要向下滑一整屏才看到「研究订单 / 制备 / 设备 / 市场」页签；制备列表 24 项与双栏市场同样极长且滚动后丢失金币/RP 与页签上下文。
- **竖屏改造**：
  - 顶部吸顶 **经营资源 HUD + 5 段模块页签**（`订单` | `制备` | `设备` | `市场` | `总览升级`），随时可见金币、RP、实验室等级与可交付红点，且首屏直接展示活跃研究订单与快捷「查看 2D 实验台 / 升级」状态条（点击直达 `总览升级` 页签查看完整 2D 等距实验台、条件标签、升级需求与经营日志）。
  - `制备` 页签：吸顶搜索框 + `仅看可生产` 筛选开关；配方卡片内采用大触控批量步进（`- / 数量 / +`）+ 一键「执行生产」。
  - `市场` 页签：增加 `我的库存` / `采购市场` 子切换，避免先滑完所有库存才能采购原料。
  - `最近经营日志` 收纳进可展开折叠区（`<details>`），不拖长主工作区。
- **横屏改造**：左栏（38%，内部滚动）展示紧凑 2D 等距实验台 + 升级状态；右栏（62%）吸顶 4 模块页签 + 独立滚动内容区（2 列订单/配方/设备卡片或并列库存市场）。

### 2.6 科技研究树（`Technology.tsx`）
- **现存问题**：6 大分支 24 张卡片竖向平铺，滚动后看不到可用 RP、金币及当前分支筛选，找「可研究」科技费力。
- **竖屏改造**：
  - 顶部吸顶 **RP / 金币 / 进度条 + 横向可滑分支筛选**，新增 `可研究 (n)` 快捷过滤按钮，一键直达当前可点亮的科技。
  - 移动端默认展示紧凑卡片，前置条件、解锁效果与研究按钮层次分明。
- **横屏改造**：左栏（30%）固定资源状态 + 纵向分支导航（含各分支进度与可研究计数）；右栏（70%）内部滚动 2 列科技节点网格。

### 2.7 挑战历史（`History.tsx` — 5 个可玩章节重点重设计）
- **现存问题**：
  - 进入章节后，顶部的操作栏、大标题、材料条、200px 场景插画、声明框与折行的 5 阶段步进条占去 ~750px，导致核心实验装置与提交按钮远在首屏之外。
  - 第 01 章 3 个气瓶卡片竖排极长；第 04 章伏打电堆「添加圆片」按钮在上方、叠层柱与电压表在下方，反复上下滚；第 07 章门捷列夫卡片托盘、周期表网格与步骤 B 预言分隔极远。
- **竖屏改造**：
  - **时间线页**：紧凑续玩焦点横幅 + 分段筛选（`全部 10 章` / `5 章可玩` / `档案手稿`），紧凑章节卡。
  - **章节内统一吸顶工作栏**：
    - 第 1 行：`[← 时间线]` + 章节标题 + `[简/进]` 快捷切换 + `[背景与材料]` 抽屉开关（将场景插画、章节独立材料清单、教学声明与「重新开始」收进按需展开面板，首屏立省 500px+！）。
    - 第 2 行：单行紧凑 **5 阶段进度条**（`1背景` `2假设` `3实验` `4分析` `5揭晓`），保留纯引擎门禁状态。
