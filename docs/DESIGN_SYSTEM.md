# 视觉与交互

背景 #0E1622，卡片 #192531，悬浮 #203042，边界 #314455，科技蓝 #83CDE9，新发现 #EAC477，主文 #E2EAF6，次文 #8196AD，成功 #81C9A3，错误 #E08080。使用 CSS 自定义变量统一。

桌面实验室为仓库 / 实验台 / 手记三栏；平板右栏下移；手机实验台在上、仓库在下，底部主导航固定。最小支持宽度 360px。所有重要操作采用可访问名称，条件和设置开关暴露状态；详情可 Escape 关闭。

本地 SVG 图形按 liquid/gas/metal/crystal/material 共享几何与光照，iconId 决定图形族，color 仅是游戏配色。无 Emoji、外链图片或在线字体依赖。图标不是物质真实照片，不应将视觉配色当作化学性质。

10 类参数动画：能量释放、气泡、沉淀、溶解、结晶、颜色、汽化、凝固、熔化、冷凝。可跳过、可关动态；发现音效默认关闭，可在设置启用，由 Web Audio 本地合成。

待进一步视觉验收：具体反应颜色、粒子与物理现象匹配，iOS 安装图标，触控拖放与长按详情。目前点击添加与详情按钮是手机的可靠操作路径。
