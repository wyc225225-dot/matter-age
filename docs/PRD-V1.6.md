# 物质纪元 Matter Age

## V1.6 游戏性增强与挑战历史开发任务书

## 01｜项目定位

物质纪元是一款融合化学沙盒、科学探索、实验模拟、历史剧情、资源经营与科技发展的教育型策略游戏。

在现有 V1.0 基础物质合成和 V1.5 定量化学系统的基础上，本阶段重点增强游戏性、长期成长体验、资源价值与科学探索的沉浸感。

玩家从基础物质研究开始，通过实验发现、资源采集、研究委托、科技升级、经典历史实验和实验室建设，逐步建立自己的科学研究体系。

长期产品目标是构建一款可持续扩展的科学文明沙盒游戏。

## 02｜整体产品架构

### 2.1 六大游戏模式

| 游戏模式  | 核心玩法            | 开发阶段     |
| ----- | --------------- | -------- |
| 自由探索  | 物质合成、实验发现、图鉴收集  | 已规划，继续完善 |
| 关卡挑战  | 化学谜题、定量计算、资源限制  | 已规划，继续完善 |
| 实验室经营 | 资源采集、订单交付、设备升级  | 本阶段开发    |
| 挑战历史  | 经典实验、历史剧情、科学推理  | 本阶段开发    |
| 世界探索  | 区域解锁、资源发现、探索事件  | 本阶段基础开发  |
| 工业文明  | 自动化生产、工业网络、文明发展 | 后续开发     |

### 2.2 三种游戏难度

**简单模式**

- 物质类型组合。
- 反应条件选择。
- 催化剂选择。
- 自动判定反应结果。
- 无需计算物质份数。

**进阶模式**

- 物质份数组合。
- 化学方程式配平。
- 反应物消耗计算。
- 产物数量计算。
- 剩余物质计算。
- 元素守恒验证。

**困难模式**

- 真实实验室流程的虚拟模拟。
- 实验仪器选择。
- 质量、体积及浓度。
- 实验操作顺序。
- 实验现象观察。
- 实验数据分析。
- 实验报告。

困难模式暂时保留扩展接口，后续独立开发。

游戏模式与难度等级采用独立架构。不同模式可以根据自身玩法支持对应难度。

### 2.3 共享基础系统

所有游戏模式共享：

- 物质数据库。
- 化学反应数据库。
- 化学计量引擎。
- 实验条件系统。
- 实验动画系统。
- 物质图鉴。
- 科学知识数据库。
- 成就系统。
- 科技研究系统。
- 本地存档系统。

禁止为不同游戏模式重复建设独立的化学反应引擎。

## 03｜核心游戏循环

建立以下长期成长循环：

资源采集 → 实验研究 → 物质发现 → 订单交付 → 获得奖励 → 科技研究 → 实验室升级 → 解锁新区域 → 获取新资源。

辅助成长循环：

- 历史挑战 → 科学发现 → 历史档案 → 博物馆收藏。
- 定量挑战 → 效率优化 → 研究奖励 → 高级科技。
- 区域探索 → 稀有材料 → 特殊任务 → 新区域。
- 物质发现 → 图鉴研究 → 关联反应 → 新物质发现。

每一种具有实际游戏价值的物质，至少应具备以下用途之一：

- 作为其他反应的原料。
- 用于研究订单。
- 用于设备建设。
- 用于科技研究。
- 用于挑战关卡。
- 用于历史实验。
- 用于特殊收藏。

## 05｜世界探索系统

### 5.1 世界地图

第一阶段采用可交互的区域地图，无需开放世界、角色移动或实时地形渲染。

每个区域拥有独立的视觉场景、资源类型、解锁条件和探索任务。

| 区域    | 主要资源         | 研究方向   |
| ----- | ------------ | ------ |
| 原始森林  | 水、木材、植物      | 基础自然材料 |
| 矿石山脉  | 铁矿、铜矿、石英、石灰石 | 矿物与冶金  |
| 海洋与盐湖 | 海水、盐类、贝壳     | 溶液与分离  |
| 火山地带  | 硫磺、火山岩、矿物    | 无机化学   |
| 工业遗址  | 金属废料、合金、加工材料 | 工业材料   |
| 未来科技城 | 高级材料、电子材料    | 现代科技   |

本阶段优先实现前三个区域，其余区域保留地图入口和解锁预告。

### 5.2 资源采集

每个区域包含：

- 可采集资源。
- 资源产量。
- 采集成本。
- 区域探索等级。
- 特殊发现事件。
- 区域研究任务。
- 资源解锁条件。

玩家通过采集获得经营模式的有限物质库存。

基础资源需要提供稳定、可重复的获取方式，避免因资源耗尽导致游戏无法继续。

### 5.3 探索事件

探索事件采用数据驱动设计。

事件类型：

- 发现新矿物。
- 发现未知样本。
- 获得科学手稿。
- 发现历史仪器。
- 获得额外资源。
- 解锁特殊研究任务。
- 遇到需要科学推理的区域谜题。

随机性仅用于游戏事件与资源奖励，化学反应结果继续由确定性规则引擎计算。

## 06｜实验室经营系统

### 6.1 实验室等级

| 等级   | 名称     | 核心能力        |
| ---- | ------ | ----------- |
| Lv.1 | 基础实验室  | 基础实验、混合、研磨  |
| Lv.2 | 化学研究室  | 分离设备、定量研究   |
| Lv.3 | 工业实验室  | 批量加工、工业订单   |
| Lv.4 | 先进研究中心 | 高级材料、自动化研究  |
| Lv.5 | 科学研究基地 | 大型研究项目、工业网络 |

本阶段实现 Lv.1 至 Lv.3，后续等级保留扩展接口。

实验室升级需要满足：

- 金币要求。
- 研究点要求。
- 指定物质材料。
- 前置科技。
- 研究任务完成条件。

### 6.2 实验室设备

初步规划：

| 设备     | 功能      |
| ------ | ------- |
| 基础实验台  | 普通物质组合  |
| 加热设备   | 虚拟热反应   |
| 研磨设备   | 材料加工    |
| 分离设备   | 混合物分离   |
| 电解设备   | 虚拟电化学反应 |
| 精密天平   | 定量研究    |
| 冷却设备   | 状态变化    |
| 高温加工设备 | 材料研究    |
| 批量反应设备 | 多份物质加工  |
| 自动化设备  | 后续生产系统  |

每种设备包含：

- 设备等级。
- 建造成本。
- 升级成本。
- 支持的反应条件。
- 处理容量。
- 运行效率。
- 前置科技。
- 能源需求，后续启用。

设备解锁限制仅应用于经营模式。

自由探索模式保留原有实验条件，避免经营进度阻碍知识学习。

### 6.3 实验室视觉成长

实验室升级后需要产生可感知的视觉变化。

包括：

- 实验台外观变化。
- 设备数量增加。
- 仪器精度提升。
- 背景场景变化。
- 收藏品展示。
- 实验室装饰。

本阶段采用二维场景与设备卡片实现，无需开发完整3D实验室。

## 07｜经济与资源系统

### 7.1 核心经济资源

**金币**

获取方式：

- 完成订单。
- 完成经营任务。
- 出售物质。
- 区域探索奖励。

消耗方式：

- 购买材料。
- 建造设备。
- 升级实验室。
- 解锁部分区域。

**研究点**

获取方式：

- 首次发现物质。
- 首次验证反应。
- 完成研究任务。
- 完成历史挑战。
- 完成定量挑战。

消耗方式：

- 科技研究。
- 高级研究项目。
- 特殊实验设备解锁。

**能源**

本阶段保留数据结构，后续工业生产版本正式启用。

避免在经营系统初期引入复杂的能源供给限制。

### 7.2 库存系统

不同游戏模式采用独立库存策略。

自由探索：

- 已解锁物质无限供应。
- 不消耗经营库存。

关卡挑战：

- 独立的关卡库存。
- 根据关卡规则限制份数。
- 重置后恢复初始库存。

实验室经营：

- 有限物质库存。
- 采集、购买和生产增加库存。
- 实验、订单和设备建设消耗库存。
- 生成物进入库存。
- 剩余物质正确返还。
- 催化剂按照规则处理。

挑战历史：

- 使用章节专属实验材料。
- 不消耗经营库存。
- 章节奖励可以进入全局成长系统。

### 7.3 经济平衡

必须避免：

- 重复领取首次发现奖励。
- 重复提交同一订单获得无限收益。
- 负数库存。
- 重复扣减物质。
- 通过存档刷新重复发放奖励。
- 所有基础资源耗尽后无法继续游戏。
- 利用简单模式的无限供应转移资源到经营模式。

所有经济参数通过独立配置文件管理，支持后续数值调整。

## 10｜挑战历史系统

英文名称：Challenge History。

挑战历史作为独立的核心游戏模式。

玩家进入不同历史时期，通过科学实验、证据分析、假设验证与推理，重新体验具有历史意义的科学发现。

### 10.1 核心玩法

每个历史章节包含五个阶段：

第一阶段：历史背景。

介绍时代背景、科学认知、研究人物和尚未解决的问题。

第二阶段：提出假设。

玩家根据历史线索选择或建立科学假设。

第三阶段：经典实验。

通过虚拟仪器、实验材料、数据模拟或科学谜题完成研究任务。

第四阶段：证据分析。

根据实验现象、测量结果或数据规律判断科学结论。

第五阶段：历史发现。

揭晓真实历史、科学理论、人物贡献及其后续影响。

实验结果揭晓之前，应尽量避免直接展示最终答案。

### 10.2 历史时间轴

历史模式采用横向或纵向可交互时间轴。

| 章节 | 年代         | 章节名称      | 科学主题    |
| -- | ---------- | --------- | ------- |
| 01 | 1770年代     | 空气中的秘密    | 氧气发现    |
| 02 | 18世纪后期     | 消失的质量     | 质量守恒    |
| 03 | 1780年代     | 水的真正身份    | 水的组成    |
| 04 | 1800年      | 人类的第一块电池  | 伏打电堆    |
| 05 | 1828年      | 生命物质的边界   | 人工合成尿素  |
| 06 | 1830年代     | 电流的化学法则   | 电解定律    |
| 07 | 1869年      | 尚未发现的元素   | 元素周期表   |
| 08 | 1898年      | 矿石中的未知信号  | 放射性元素发现 |
| 09 | 1909—1911年 | 原子内部的世界   | 原子核模型   |
| 10 | 1909—1913年 | 来自空气的农业革命 | 合成氨技术   |

以上年代和历史归属需要在正式内容开发时进行史料核验。

第一阶段完整开发章节01、02、03、04、07。

其余章节建立数据结构、时间轴入口与内容预告。

### 10.3 第一批历史章节详细设计

#### 章节01：空气中的秘密

历史人物：

约瑟夫·普里斯特利、卡尔·威廉·舍勒及相关研究者。

研究问题：

空气是否由不同性质的气体组成？

游戏任务：

- 阅读历史研究线索。
- 观察虚拟气体实验现象。
- 比较不同气体的性质。
- 判断未知气体。
- 完成氧气发现档案。

核心玩法：

未知物质鉴定、实验观察、证据推理。

奖励：

- 氧气研究档案。
- 历史勋章。
- 研究点。
- 纪念仪器。

#### 章节02：消失的质量

历史人物：

安托万·拉瓦锡及相关研究者。

研究问题：

物质发生化学变化后，总质量是否发生变化？

游戏任务：

- 选择开放或封闭的虚拟实验系统。
- 比较反应前后的测量数据。
- 分析物质进出系统的影响。
- 完成质量守恒推理。

核心玩法：

实验对照、质量计算、科学假设验证。

模拟数据必须明确标注为教学数据。

#### 章节03：水的真正身份

历史人物：

亨利·卡文迪许、安托万·拉瓦锡及相关研究者。

研究问题：

水是基本元素，还是由其他物质组成的化合物？

游戏任务：

- 分析虚拟反应记录。
- 识别反应物和产物。
- 完成化学方程式。
- 解释水的组成。

核心玩法：

物质合成、方程式配平、科学理论推理。

危险反应仅采用抽象模拟与数据分析。

#### 章节04：人类的第一块电池

历史人物：

亚历山德罗·伏特。

研究问题：

不同材料的组合能否产生持续电流？

游戏任务：

- 选择虚拟材料组件。
- 排列电池结构。
- 观察模拟电流变化。
- 比较不同结构的结果。
- 完成伏打电堆研究。

核心玩法：

组件排列、结构谜题、能量转换。

#### 章节07：尚未发现的元素

历史人物：

德米特里·门捷列夫及元素周期分类研究者。

研究问题：

不同元素之间是否存在可预测的规律？

游戏任务：

- 获得元素卡片。
- 根据性质和历史数据进行分类。
- 排列元素卡片。
- 识别缺失位置。
- 预测未知元素性质。
- 对照后续科学发现验证预测。

核心玩法：

卡片排列、逻辑推理、规律识别。

### 10.4 历史章节难度

简单难度：

- 观察实验现象。
- 选择物质。
- 完成基础推理。
- 允许较多提示。

进阶难度：

- 化学计量计算。
- 方程式配平。
- 数据分析。
- 有限实验次数。
- 更少提示。

困难难度：

- 虚拟实验仪器操作。
- 实验流程设计。
- 测量误差分析。
- 完整科学研究报告。

本阶段优先实现简单和进阶难度。

### 10.5 历史评价体系

每个章节记录：

- 实验完成情况。
- 科学结论正确率。
- 实验次数。
- 提示使用次数。
- 证据收集完成度。
- 章节探索完成度。

评价等级：

- 一星：完成历史研究。
- 二星：完成核心证据收集与正确推理。
- 三星：满足章节规定的独立研究条件。

允许玩家重复挑战，提高章节评价。

首次奖励和重复挑战奖励独立配置。

### 10.6 历史内容规范

必须区分：

- 真实历史事件。
- 历史人物的实际贡献。
- 游戏化剧情。
- 教学模拟数据。
- 虚构对白。
- 简化实验模型。

避免将多人共同完成的科学发现完全归属于单一人物。

不得虚构历史原始实验记录。

涉及有毒物质、放射性材料、高风险化学反应的章节，只提供安全的虚拟模拟、科学推理和抽象数据分析。

每个正式章节需要具有参考来源和内容审核状态。
