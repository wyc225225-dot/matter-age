# Matter Age · V1.6 经济与成长平衡（ECONOMY BALANCE）

## 1. 三类成长资源职责分离

- **金币（`coins`）**：实验室经营流通货币，用于原料采购、付费野外采集、科技研究、设备建造/升级与实验室扩建。
- **研究点（`researchPoints` / RP）**：可消费科研资源，用于解锁科技树节点、建造设备与实验室升级。
- **累计研究经验（`experience` / XP）**：只增不减的累计成长值，决定 7 级研究者称号（`LV.1 科学学徒` → `LV.7 科学探索大师`）；消费研究点**绝不**降低经验或等级。

## 2. 防刷与防死锁机制

- **幂等事件账本（`claimedRewardIds`）**：首次物质发现、首次反应完成、首次配平、各类挑战首通、历史章节首通、区域任务与成就奖励均以唯一事件 ID 登记，彻底防止刷新重放、重复领奖或旧存档迁移重放历史首发现奖励。
- **零金币 / 空库存防死锁**：世界探索「原始森林」内置两个永久免费采集点（`林间溪泉`：水×4、空气×2；`古木与炭窑遗址`：木材×3、木炭×2、碳×1）。即使玩家金币归零且经营库存清空，仍可通过免费采集获取基础原料并出售换币或生产交付订单，已在单元测试中显式验证。
- **原子交易校验**：购买、出售、生产、订单交付、设备建造、科技解锁与实验室升级均在纯引擎中完成前置校验与一次性状态变更，拒绝负数库存与重复扣费。

## 3. Lv.1 → Lv.2 → Lv.3 可达性数值验证

独立经济配置位于 [economy.json](file:///G:/化学小游戏/src/data/economy.json)，订单位于 [orders.json](file:///G:/化学小游戏/src/data/orders.json)，科技位于 [technologies.json](file:///G:/化学小游戏/src/data/technologies.json)。

- **初始状态**：`120 金币`、`30 RP`、`0 XP`、Lv.1 基础化学工作台（含 `基础实验台 Lv.1`）、初始有限库存（水 8、空气 4、木材 4、石英砂 4、铁 4、氧化钙 2、过氧化氢 2、二氧化锰 1）。
- **Lv.1 → Lv.2 门槛**：`240 金币`、`40 RP`、`8` 种已发现物质、前置科技 `标准实验室扩建规划`。
- **Lv.2 → Lv.3 门槛**：`520 金币`、`85 RP`、`14` 种已发现物质、前置科技 `高级实验中心工程`。
- **自动化全链路模拟验证**：`simulateProgressionToLabLv3()`（运行于 `npm run validate` 与 `tests/unit/v16.test.ts`）从全新初始存档出发，仅执行合法采集/采购/共享化学引擎生产/订单交付/科技解锁/设备建造操作，**102 步零死锁稳定达成 Lv.3 高级定量实验中心**。
